# Données ouvertes du jeu Viabus

Le jeu Roblox **Viabus** utilise les vraies lignes de bus de 11 villes françaises, tirées des horaires
officiels publiés sur transport.data.gouv.fr. Voici les bases dérivées utilisées par le jeu, ville par ville,
chacune **sous la licence de sa source** (voir le LISEZMOI de chaque dossier).
